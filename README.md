# 安麗 健管45天完整中文版手冊 (45Days Health Transformation System)

> 🌿 專為健康管理、生活型態重塑與體態雕塑設計的 45 天系統化方案。

## 🌐 線上預覽與使用
- **線上閱讀網址**：[https://garfiwang.github.io/amway-45days/](https://garfiwang.github.io/amway-45days/)
- **行動裝置與平板**：完全支援響應式直式瀏覽、連續長捲軸閱讀與手勢滑動。

## ✨ 核心特色
1. **100% 原始排版視覺保留**：原版插圖、圖表、色塊、icons 全數保留，韓文文字皆以精緻台灣官方術語精準替換覆蓋，渲染 20 張高解析度繁中直式圖檔。
2. **多模式互動體驗**：
   - 🖼️ **單頁簡報模式**：上一頁 / 下一頁切換，支援鍵盤左右箭頭導航。
   - 📜 **連續捲軸手冊模式**：像電子書一樣 1~20 頁順暢往下瀏覽。
   - 🔄 **中韓對照即時切換**：繁中版 / 韓文原版 / 左右並排 (Split View)。
3. **20 頁講師公版講稿抽屜**：每一頁皆提供核心觀念摘要、講師推薦話術與推薦營養品清單，支援一鍵複製。
4. **🖨️ A4 直式列印與匯出 PDF**：內建 `@media print` 專用分頁排版，可一鍵轉存為高畫質實體手冊或電子書。
